**MicroLabel** — uppercase, wide-tracked micro-label for step markers and section eyebrows.

```jsx
<MicroLabel>STEP 03 · CAPTURE</MicroLabel>
<MicroLabel tone="accent">EXPLICIT NEED</MicroLabel>
```

`tone`: `muted` (default) · `ink` · `accent` (reserve for the rec-type label). `as` sets the tag (default `span`).

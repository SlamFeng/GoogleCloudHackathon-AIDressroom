**MicroLabel** — uppercase, wide-tracked micro-label for step markers and eyebrows.

```jsx
<MicroLabel>Step 01 · Privacy</MicroLabel>
<MicroLabel tone="accent">Explicit need</MicroLabel>
```

Tones: `muted` (default) · `accent` (cobalt — rationed) · `on-dark` (full white). Renders as `<span>` by default; set `as` for headings.
